## Interview Tips

- Practice fast input until it is automatic.
- Prefix sum solves many subarray sum questions.
- Sliding window works when the window condition moves monotonically.
- Hashing helps with anagram, duplicate, and target-index problems.

## Hidden Traps

- Company tests often include small edge cases, not only large cases.
- Be careful with input format. Wrong parsing can fail even when logic is correct.
- For subarray questions, clarify whether empty subarray is allowed.
