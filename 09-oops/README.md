# 09 - OOP

OOP appears in interviews as both theory and implementation. Keep explanations simple and example-driven.

## Files

- `encapsulation.py`
- `inheritence.py`

## Interview Tips

- Encapsulation means keeping data and behavior together while controlling direct access.
- Inheritance means reusing and extending behavior from a parent class.
- Be ready to explain class, object, constructor, instance variable, and method.

## Hidden Traps

- Do not overuse inheritance when composition is simpler.
- In Python, name mangling with `__name` is not the same as true private access in languages like Java.
- `self` is the current object, not a keyword magic trick.
