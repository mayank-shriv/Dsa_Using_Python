## Interview Tips

- For math problems, write the formula or invariant before coding.
- For recursion, always define base case, recursive call, and what each call returns.
- For second largest, handle duplicates and arrays with fewer than two distinct values.
- For palindrome, compare from both ends instead of reversing when space matters.

## Hidden Traps

- `n == 1` is not prime.
- Missing number problems can overflow in some languages with sum formula; XOR is a useful alternative.
- In recursion, forgetting to return the recursive result is a common silent bug.
